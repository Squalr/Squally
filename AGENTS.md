# Important Information
Information found in initial audit:
- `UseNewAnimationSystem` is hardcoded `true` in `SmartAnimationNode.cpp`, so all current behavior depends on the new runtime path.

Information discovered during iteration:
- `SmartAnimationNode::getAnimationPart()` returned `nullptr` on the new runtime because only the legacy Spriter2dX entity path exposed parts.
- The new runtime ignored `AnimationPlayMode`; timeline time always wrapped, so callback/pause/return-to-idle clips effectively looped forever.
- Bone timeline events never advanced actual runtime bones because `SpriterAnimationTimelineEventAnimation::canAdvance()` returned false for bone events.
- Rotation deltas ignored Spriter `spin`, and cascade rotation ignored parent reflection signs from negative scales.
- `SpriterAnimationNode::buildSprites()` erased `folder/file` entries after first use, which skipped later timelines that reuse the same source sprite.
- Mainline rebuilds were logically reparenting sprites to the animation root instead of their owning parent bones, which collapsed many poses until sprite-to-bone logical parenting was restored.
- The compare harness originally sampled whatever real frame `dt` had advanced to, even when recording a named sample timestamp; exact-time seeking for both runtimes was added so reruns now produce stable worst-sample BMPs and comparable metrics.
- The new runtime's exact-time seek path initially stamped the active timeline segment's start key instead of sampling interpolation at the requested time, so exact-time compare captures at non-key times overstated drift until `SpriterAnimationTimeline::applyCurrentAnimationState()` was taught to sample the active event state directly.
- Segmentized animation events were still choosing their interpolation target from the next mainline slice instead of the next distinct timeline key, which compressed reused-key loop interpolation late in `KillingMachine6 Walk`; sampling each segment against the source timeline key's real window (including wrap to loop start) removed the remaining `bone_027`/`bone_028` and `beam_bellow*` drift.
